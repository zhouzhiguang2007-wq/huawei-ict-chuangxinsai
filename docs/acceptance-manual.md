# 人工验收清单

代码层基线由 `scripts/e2e_smoke.py` 覆盖；本清单是平台内的真实验收，需要截图或录屏留证。

## A. 安装与初始化

| # | 操作 | 通过标准 | 证据 |
|---|---|---|---|
| A1 | 导入 9 个 skill 到平台 | 列表显示 9 个，名称与 `plugin.json.skills` 一致 | 截图 |
| A2 | 部署后端并 seed | `python -m travel_shared.seed_knowledge` 成功 | 日志 |
| A3 | 后端健康检查 | `POST /v1/tools` 返回 200；错误 token 返回 401 | 请求/响应 |
| A4 | Agent 绑定工具 | 24 个 action 可见或 HTTP 工具可调用 | 工具列表截图 |

## B. skill 触发覆盖

| # | 操作 | 通过标准 |
|---|---|---|
| B1 | 发一句泛泛「我想去旅游」 | 编排器启动并逐轮提问，而不是直接生成 |
| B2 | 完成 13 步问卷 | 目的地/出发地/时间/人数/预算/风格/交通/住宿/拍照/复核/手册/应变/空档均有记录 |
| B3 | 观察调用序列 | 需求→规划→住宿→拍照→复核→手册 均出现 |
| B4 | 发「高铁晚点了」 | 调用重排，且不重写已发生段 |
| B5 | 发「还有两小时去哪」 | 调用空档，给出安全缓冲 |

## C. 数据与实时性

| # | 操作 | 通过标准 |
|---|---|---|
| C1 | 查真实车次 | 返回车次/时刻/票价/余票，标注 `12306-mcp` 与查询时间 |
| C2 | 关闭 12306-mcp 重查 | 标 `tool_unavailable` 或未知，不编造 |
| C3 | 两个用户用同一 trip_id | 互相看不到对方会话 |
| C4 | 重启后端后读会话 | 数据仍在（持久化磁盘生效） |
| C5 | 旧偏好迁移 | 迁移后偏好可见，备份文件存在 |

## D. 交付物

| # | 项 | 通过标准 |
|---|---|---|
| D1 | 离线手册 | 手机浏览器可打开，无网络可看 |
| D2 | 复核报告 | 列出问题与修正建议，未通过项不标记为完成 |
| D3 | 可视化 Demo | 平台内可演示，或提供录屏 |

## E. 判定

全部 A/B 项通过 = 可演示；C/D 项通过 = 可交付。任一 P0 项失败需先修复再验收。
