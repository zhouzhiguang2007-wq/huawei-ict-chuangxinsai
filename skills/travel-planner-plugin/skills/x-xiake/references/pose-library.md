# 姿势种子库

按风格 × 人数分类。每张姿势卡含机位、角度、站位分解、手部动作、表情、肢体动作分步指令、拍摄者分步指令、避坑。用户指定风格直接取对应类；未指定按景点默认风格（见 spot-library 适配项）。

本库只提供姿态要点；最终可视化用有出处的景点照片与完整人物，按 scene-overlay.md 制作标注图。

## 国风

### 国风·单人 A：侠客持伞

- 机位：拍摄者蹲下，侧前方 3 步
- 角度：仰拍 15 度，侧身对镜头
- 站位分解：侧身，左脚前右脚后，重心在后脚，身体微挺
- 手部动作：右手举油纸伞半遮面（伞柄在右手，伞面斜遮右眼上方），左手自然下垂略离身体
- 表情：微抬头看远方，不看镜头
- 肢体动作分步指令：
  1. 侧身站定，左脚迈出半步
  2. 右手举起伞柄，伞面斜遮至右眼上方
  3. 左手自然垂落，手指微张
  4. 下巴微抬，目光投向远方
  5. 定住 3 秒等风吹伞沿
- 拍摄者分步指令：
  1. 蹲下到膝盖高度
  2. 退到侧前方 3 步
  3. 手机仰拍 15 度
  4. 对焦脸部，等伞沿飘动
  5. 连拍 5 张
- 照片标注重点：侧身 + 右手举伞半遮面；将动作点标到完整人物或现场人像上。
- 避坑：别用广角，会拍成大长腿漫画脸

### 国风·单人 B：侧身回眸

- 机位：拍摄者站侧后方两步
- 角度：平举到肩膀高度，侧面拍
- 站位分解：侧身背对镜头，头微转回看，步伐定住
- 手部动作：双手交叠身前或持扇
- 表情：回眸，嘴角微收不笑
- 肢体动作分步指令：
  1. 背对镜头站定，双脚平行
  2. 双手交叠于身前
  3. 头向镜头方向转回三分之二
  4. 嘴角微收，眼神定住
  5. 定住 2 秒等拍摄者喊名
- 拍摄者分步指令：
  1. 站她侧后方两步
  2. 手机平举到肩膀高度
  3. 叫她名字
  4. 等她回头瞬间
  5. 连拍 3 张
- 照片标注重点：背对 + 头回转 + 双手交叠身前；将动作点标到完整人物或现场人像上。
- 避坑：回眸别转太多，侧脸最美是三分之二

### 国风·双人：并肩信步

- 机位：拍摄者退后四步，正面或侧前方
- 角度：平举到胸口高度，正面拍
- 站位分解：两人并肩，一前一后半步差，留半臂距离
- 手部动作：内侧手自然摆动，外侧手可持伞或扇
- 表情：都看前方或互看
- 肢体动作分步指令：
  1. 两人并肩站定，留半臂距离
  2. 一人前迈半步，错开半个身位
  3. 内侧手自然摆动
  4. 都看前方或互看
  5. 走第三步时定住
- 拍摄者分步指令：
  1. 退后四步
  2. 手机举到胸口高度
  3. 等他们走到第三步
  4. 连拍 5 张
  5. 挑步态最自然的那张
- 照片标注重点：两人并排 + 一前一后 + 内侧手摆动；将动作点标到完整人物或现场人像上。
- 避坑：两人别并排贴太紧，留半臂距离更出片

### 日系·双人：一前一后

  4. 后者抬头看前者
  5. 回头瞬间定住

  3. 等前者回头

- 照片标注重点：两人前后 + 前者回头 + 后者抬头；将动作点标到完整人物或现场人像上。
- 避坑：别两人都看镜头，互动感才对味

## 群像
