# 景点出片教练

## 何时使用

用户到了景点想把人拍好，但同伴不会拍、又不想找陌生人时使用。根据位置、人数、关系、风格、社恐等级和光线环境，给出机位焦段、姿势方案、给拍摄者的口语化指令和避坑提示；拍完发照片来做选片、调色建议和朋友圈文案。

触发场景：用户说「在 XX 怎么拍出片」「我俩他不会拍教教他」「社恐不想找路人怎么拍」「这张拍得行不行帮我选选」「逆光背景有垃圾桶怎么弄」等。

## 何时不用

- 找陌生人约拍撮合：不撮合摄影师或路人。
- 成片精修或滤镜：只给调色建议；为拍摄教学制作的标注图属于本 Skill 的交付。
- 社交发布：不代发朋友圈或平台。
- 实时视频流引导：不接管摄像头视频流连续指挥，只做拍照-反馈的断点指导。
- 替用户按快门：不控制相机。

## 输入澄清

收到请求后复用已知条件，每轮只问**一个**影响当前拍摄的缺项，等用户回答再问下一项；用户一次给多项就全部记录。作为完整旅游规划的一环时，出发日期、预算和游玩天数由需求分析环节先逐轮取得，不能替用户猜；现场临时拍照请求不强迫询问与拍摄无关的旅游预算和天数。

1. 当前位置：景点名或具体地点（如「西湖断桥」「外滩观光台」）。
2. 拍摄人数：1 人 / 2 人 / 3-5 人 / 家庭（含老人小孩）。
3. 拍摄对象关系：自拍 / 朋友互拍 / 路人帮拍 / 情侣 / 家庭。
4. 风格偏好：国风 / 日系 / 胶片 / 大气 / 可爱。未指定时按景点默认推荐。
5. 社恐等级：敢找路人 / 只敢让熟人拍 / 完全不想跟人说话。影响是否推荐路人帮拍和指令复杂度。
6. 当前环境：光线（顺光/逆光/阴天/夜景）、人流量（拥挤/空旷）。可让用户发一张现场照判断。

用户主动发现场照片时，直接从照片读取光线和背景，不再追问环境。

## 核心流程

按以下 5 步执行，每步详细规则见 @references/coach-flow.md。景点照片式指导图的制作见 [场景叠加](references/scene-overlay.md)。

### Step 1 场景识别

匹配景点机位。加载 @references/spot-library.md 查询该景点是否有种子机位。

- 命中种子库：参考建议机位、焦段、时段与注意事项；根据现场照片和开放区域复核，种子库不是实测坐标。
- 未命中：让用户描述或发现场照，反推可用机位（光线方向、背景元素、可站位置）。网络可用时可检索景点公开机位信息补充。

### Step 2 姿势生成

根据人数、关系、风格，从 @references/pose-library.md 抽 2-3 套姿势方案。

每套包含：站位、手部动作、表情、机位、角度、肢体动作分步指令、给拍摄者的分步指令和避坑。旅游报告或用户要求可视化时，按 [照片式构图流程](references/scene-overlay.md) 从有来源的**真实景点照片**制作拍照指导图：核对地标身份、取得可用原图或合规截图、叠加人物姿态与构图标注、检查成图、记录来源，再嵌入报告。优先让用户不看标题也能认出具体景点。

拍照指导图分成两张或一张双面板：**场景构图图**标人物占画面比例、头顶留白、背景主景、机位与取景框；**姿态细节图**标身体角度、手部动作、视线和拍摄者口令。有人物的现场照优先直接在真实人物上标注；没有人物时，可叠加明显标为“合成示意”的完整人物素材或具备衣着轮廓的人体剪影。不得把简笔火柴人或脱离景点的单独 SVG 当最终可视化。参考照必须保留景点名称、原发布页与拍摄时间（可得时）；不能把合成图说成当天现场实拍或声称有传播授权。

- 单人：抽 3 套不同类型（如站/走/背影）。
- 双人/多人：抽 2 套互动方案 + 1 套单人备选。
- 家庭：优先坐姿或互动方案，照顾老人小孩。

### Step 3 拍摄者指令

为每套姿势生成给拍摄者的口语化指令。规则见 @references/coach-flow.md。

指令必须是拍摄者能直接听懂执行的大白话，包含：站位距离、手机高度角度、按快门时机、连拍张数。

示例：「你退后三步，手机举到她肩膀高度，仰拍 15 度，等她走到第三步时连拍 5 张。」

### Step 4 避坑检测

分析当前光线和背景，给出避坑提示。

- 光线：逆光提示补光或换角度；正午顶光提示找阴影。
- 背景：垃圾桶、杂乱人流、割裂线条提示避开或调整站位。
- 构图：人头被切、地平线穿头、主体太小提示修正。

用户发了现场照时，从照片直接判断。未发照时按用户描述的环境给通用提醒。

### Step 5 出片后处理

用户拍完发照片过来时执行。加载 @references/output-format.md 取格式。

- 选片：从连拍中挑最好的 1-3 张，说明挑选理由（表情/姿态/构图）。
- 调色建议：按所选风格给调色方向（色温、对比、饱和），不真改图。
- 朋友圈文案：给 2-3 条备选文案，贴合景点和风格。

后期处理时机由用户定：现场穿插做或回家批量做均可。

## 降级规则

| 失败条件 | 降级方式 | 限制 |
|---|---|---|
| 用户未发照片、纯文字描述 | 搜索对应景点的官方或可追溯照片做标注；找不到时只给机位/姿势/指令，不做照片分析 | 无法精确判断现场光线背景 |
| 模型不支持读图 | 同上，全程基于文字描述 | 无法做选片和照片级避坑 |
| 景点未在种子库 | 让用户描述现场或发照反推机位；网络可用时检索补充 | 机位精度依赖用户描述 |
| 网络不可用 | 只用种子库，不检索外部机位信息 | 未覆盖景点只能现场反推 |

降级结果标注限制，不把推断写成实测。

## 输出格式

完整输出格式和西湖断桥实例见 @references/output-format.md。每条现场回复包含可查看的拍照指导图（有适用照片时）、机位焦段、姿势方案、拍摄者指令、避坑提示；后处理回复包含选片、调色、文案。

## 质量自查

每次输出前检查：

- [ ] 不看标题也能从原图和最终图辨认具体地标；桥、楼、匾额名称已与来源核对，未把相似建筑误标为该景点。
- [ ] 原图或截图的发布页、发布方、取得方式和可用范围已记录；截图没有被当成图片授权。
- [ ] 机位和焦段已给出，未命中种子库时说明了来源（现场反推或检索）。
- [ ] 有适用景点照片时，输出了照片式指导图，人物为真实照片/合成完整人物/完整剪影，构图框、三分线、机位和动作标签可读；原图来源与合成标记清楚。
- [ ] 合成后复查牌匾、建筑与人数；人物站位不占台阶、通道或危险区域，无法核实时改为独立姿态示意并标“现场确认”。
- [ ] 姿势方案数量符合人数规则，每套含站位/动作/表情。
- [ ] 拍摄者指令是大白话，含距离/高度/时机/张数。
- [ ] 避坑提示覆盖光线和背景至少一项。
- [ ] 后处理回复含选片理由，不只说「这张好」。
- [ ] 降级时标注了限制，未把推断写成实测。
- [ ] 没有约拍撮合、成片精修、社交发布、接管摄像头的内容。

## 停止条件

- 用户要求成片精修或代发社交：说明不做，停止该子任务；拍照教学标注图继续按本流程制作。
- 用户要求实时视频流连续引导：说明不做，指明需独立 app，停止该子任务。
- 用户要求撮合陌生人约拍：说明不做，停止该子任务。
- 景点信息完全无法获取且用户不能描述现场：无法给机位，停止 Step 1，告知用户需要至少一项信息。
