# 景点照片内的火柴人站位叠加

当用户要求“把火柴人放到景点图片中”或旅游报告需要直观看机位时使用。

1. **选图**：优先用户上传的现场照；否则找景点官方或可追溯的公开照片，记录页面链接、景点名及画面方位。公开图片只用于内部构图预览，报告保留原发布页；对外宣传需另确认授权。照片必须与要讨论的具体景点对应，不拿相似古建筑冒充。
2. **问缺项**：照片有了以后，若拍摄人数、风格或人流/光线无法判断，每轮只问一个关键问题。作为完整行程的拍照环节，复用上游已确认的日期、预算、天数，不重新猜测。
3. **确定安全站位**：在照片上挑不阻路、不踏花、不越栏杆、不处于车道或演出封控区的位置。无法从图片判断安全性时写“现场确认”，不要给精确米数或坐标。
4. **叠图**：保留景点照片作底图，将火柴人 SVG 以可辨识的半透明线条放在预期人物位置；用箭头标拍摄方向，写明是单人、双人或小组。移动、缩放到人物脚落在可站地面上，头部不遮挡重要景物。推荐用宿主支持的 HTML/SVG 叠层或图像编辑功能输出可查看文件；不要把孤立火柴人贴在图片旁边充数。
5. **交付**：每张图下写景点、原图来源、拟站位、手机焦段/高度、拍摄口令，以及“基于参考照的示意，现场需确认光线、人流和开放区域”。用户发现场照后再按实景调整。没有适用景点图片时给独立 SVG 并解释原因。
