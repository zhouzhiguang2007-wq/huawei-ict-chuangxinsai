# 景点照片式拍照指导图

用户提供的参考图是交付版式：真实景点背景、完整人物、黄色姿态标注、构图框和三分线、拍摄设备方位、简短中文口令。最终交付应是可直接查看的图片；网页交互页只能作补充。

## 1. 找到与机位对应的背景

先用用户提供的现场照。没有现场照时，从景区官网、地方文旅部门、官方图集、有原作者与出处的旅游平台照片中找**该景点且该角度**的照片；抖音/小红书公开帖子可发现热门场景或动作，但帖子标题和搜索摘要不能充当图片、机位或开放状态的核实依据。记录景点、画面方位、原图页面、摄影者或发布方、图像日期（可得时）、访问时间。只可见缩略图、登录墙或无权复用时，给原页面链接供用户查看，换可用的有来源照片；不得绕过访问限制。

拍照规划可参考：清明上河园[官方景区攻略](https://www.qmsyun.com/Mobile_page/o_newsinfo.php?softid=3168)列虹桥、上善门、听雨桥、丹台宫等取景地；[官方建筑页](https://www.qmsyun.com/Mobile_page/q_building.php)可核对具体建筑名。抖音公开页面仅作场景热度线索，不用它核定现场位置。龙亭和万岁山换用各自可追溯的当期照片，不能用相似古建筑代替。

## 2. 分析背景和人物可站区

识别主景、引导线、光向、杂乱物和可见步道；优先在用户现场照里确定取景。把拍照位置写成“虹桥南侧允许停留的步道”等可辨识文字。照片看不出是否可站时标“现场确认”；不依据一张照片捏造精确坐标、固定 3 米距离或全年不变的黄金光线。距离可以写“从约 2–4 米开始，按现场取景调整”。桥栏外、水边、花坛、车道和演出通道均排除。

## 3. 制作与参考图同类型的两幅标注画面

**A. 场景构图图**：背景照片铺满画面；以实线或虚线框选人物区域；标出人物放在左/右三分线、头顶留白、主景不被遮挡、手机或拍摄者方向、建议焦段和起始距离。箭头要指向实际物件，文字保持短而大。

**B. 姿态细节图**：同一背景上放大人物。优先在用户提供的人像上标肩、手、腰、膝和视线；否则用授权或生成的完整人物素材，也可用具有衣着及身体轮廓的完整人体插画。标注如“侧身约 30°”“靠墙借力”“手扶脸颊”“伞沿避开眼睛”，并给一句能照做的摄影口令。若人物为合成，画面内写“合成人物示意”。不要让线条替代人体。

每张最终图至少显示：景点名、照片来源、人物/姿态、拍摄方向、手机高度或焦段、构图依据、安全提示。图中文字不要压住脸、景区标牌或关键建筑；色彩与实景有足够对比。移动端阅读时也能看清。优先导出 PNG/JPG；如图像工具不可用，可交付可打印的 HTML/SVG 版并明确说明。

## 4. 来源、授权和现场复核

来自第三方的照片保留原页面链接及发布方，不把网络照片随意打包进公开仓库或宣传材料。能链接查看不代表有改编、再分发或商用许可。用户自己上传的现场照可按本次请求加标注；合成示意与真实现场要醒目区分。临出发或到场时核对天气、人流、开放区域、拍摄设备规则和实际光向；对方位、距离或许可不确定时直接标“现场复核”。

## 5. 交付格式

每个重点景点给 1–2 张图片或一个双面板图片，并附：原图页链接、画面所示的拍摄角度、取景范围、人物脚落点、焦段/手机高度、口语化拍摄指令、现场待核实项。若找不到可靠照片，仅交付文字机位建议和来源缺口；不能用生成的仿古场景冒充该景点。
