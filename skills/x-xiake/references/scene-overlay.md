# 景点照片式拍照指导图：从找图到交付

适用于用户要求“看得出是哪个景点”的拍照示意图，以及旅行报告里的拍照页。成品以真实、可核对的地标照片为主体，另有完整人物姿态和拍摄标注；不能用泛化古建筑、栏杆或天空冒充景点。用户提供的样例图优先决定视觉风格。最终交付可直接查看的 PNG/JPG；网页交互页可作补充。

## 1. 接收任务与挑选画面

复用行程里已有的城市、景点、人数、风格和报告尺寸；只问影响本次拍摄的关键缺项。一个景点先确定一个**具体地标及视角**，例如“清明上河园红色虹桥侧面”，而非仅写“开封古风”。列出画面必须可见的识别点（桥型、建筑正面、牌匾文字等），再找素材。多人合影另考虑人物占比和背景留白。

## 2. 找真实照片并留存来源

优先使用用户发来的现场照；其次找景区官网、地方文旅部门、官方图集或有明确原作者与原页的旅游平台照片。可用抖音、小红书的公开内容发现热门角度、动作与取景点，但帖子标题、搜索摘要和相似图片不能独自证明地标身份或开放状态。用浏览器查看原页和大图，记录：景点与视角、发布方/摄影者、原页链接、原图链接（若有）、拍摄日期（若有）、查看日期、取得方式及许可范围。

图片不能直接下载时，可对**公开可查看且本次用途允许使用的原图**截屏并裁出画面，保留原页链接和截图时间。截图只是取得图像的方法，不产生改编或公开再分发的许可；不得绕过登录墙、水印、付费或访问限制。许可不明确时，优先换用户照片或有明确授权的素材；不能把第三方照片打包进公开仓库或公开宣传材料。

## 3. 原图身份核验与选图

放大原图，关掉标题后检查是否仍能靠画面认出该地标；再与景区官方图片或说明核对桥型、楼体、匾额等识别点。只有普通栏杆、天空、服装或相似古建筑时继续找图。若景点名或视角与图不符，放弃候选，不靠标签补救。照片还需有足够空间显示完整人物和标注，主体建筑不能被人物或文字挡住。

选图时区别“画面可见的地面”和“允许站立的地方”。单张照片不能证明当前可进入、可停留或拍摄许可；台阶、入口通道、桥栏外、水边、花坛、道路和演出动线不作为默认站位。可站位置无法确认时，改用单独的姿态小图或画面边缘插图，正文写“现场确认”，不在主景上画虚假的安全落脚区。距离和光线用现场可调整的起点，不编造精确坐标或全年不变的黄金时段。

## 4. 制作双画面指导图

保持真实照片里的建筑、牌匾、桥型和色彩特征；有条件时在未改动的原图上另建人物与标注层，不让生成工具重绘关键地标。若用了生成式编辑，必须把输出与原图并排核对，桥型、屋顶和牌匾一有漂移就退回重做。两张图或一张双面板都可以：

- **场景构图**：实景为主体，标出取景框、三分线、完整人物占比、头顶留白、主景、拍摄方向、手机高度/焦段和可调整的起始距离。箭头指向画面里真实可见的物件。
- **姿态细节**：优先给用户现场照中的人物标肩、手、身体角度、视线和脚步；没有人物照时，放入授权或生成的完整人像/人体插画，画面内写“合成人物示意”。给一句能照做的拍摄口令。不要用火柴人或脱离景点的单独人像当成品。

若用两张不同来源照片分别说明全景和姿势，分别标注来源与视角，不声称它们是同一机位。图中文字短而大，避开脸、牌匾和关键建筑；至少写景点名、照片来源、合成标记、拍摄方向和现场待核实项。可用以下制作简报约束图像编辑工具：

## 5. 出图后逐项复查

同时查看原图与最终图，放大到能读清牌匾，再缩到手机屏幕大小检查文字。按顺序核对：

1. 关掉标题仍可辨认地标；建筑、桥型、匾额没有被改成另一处，景点名没有写错。
2. 人物数量、身体、手部、脚的位置自然；人物或标签没有遮住最重要的识别点。
3. 取景框、三分线、箭头与实际画面相符；起始距离/角度没有写成未经测量的事实。
4. 没有把不明区域标成安全站位；来源、合成情况和现场复核提示都能读清。

有一项失败，就定向修改标注、换照片或改用姿态插图，再复查。实际试做中曾把园内白色多孔桥误标为清明上河园的**红色虹桥**，也曾把入口台阶画为站位；这两类错误必须在交付前挡住。

## 6. 嵌入报告与交接

导出清晰的 PNG/JPG，在旅行报告中让图片紧贴对应景点的文字建议；附原页链接、发布方、视角、是否合成、可拍位置的核实状态和一句拍摄口令。多图应采用一致命名，引用路径在报告中实际打开检查。把来源记录交给行程整合环节，避免报告里把不同照片写成同一机位。公开 GitHub 仓库只提交可复用的流程和许可明确的素材；未经确认的网络照片留在获准的使用范围内。

## 无可靠照片时

若原图身份无法核对、来源不可追溯或无权用于当前交付，给用户已核实的景点页面链接、文字机位/姿势建议，并说明缺少可用照片。不可用 AI 生成的“像某景点”画面代替真实地标，也不把不完整的示意图说成照片式成品。
